# Certifications

Ce dossier regroupe **uniquement** les contenus dédiés à la **préparation de certaines certifications** du monde DevOps / Cloud Native : notes de cours, concepts clés, démonstrations et questions/réponses utiles pour la révision.

> Les contenus techniques « génériques » (non orientés examen) restent dans les dossiers thématiques du dépôt, par exemple [orchestration](../orchestration/), [observabilite](../observabilite/) ou [iac](../iac/).

### Contenus

| Répertoire | Description |
| --- | --- |
| [golden-kubestronaut](golden-kubestronaut/) | Parcours **Golden Kubestronaut** (CNCF / Linux Foundation), organisé par certification : KCNA, puis les suivantes du parcours |

#### Parcours Golden Kubestronaut

Le parcours est découpé en sous-dossiers numérotés, un par certification, afin de suivre une progression du niveau fondamental au niveau avancé.

| Sous-dossier | Certification | Statut |
| --- | --- | --- |
| [01-KCNA](golden-kubestronaut/01-KCNA/) | Kubernetes and Cloud Native Associate | En cours |

> Les autres certifications du parcours seront ajoutées progressivement, dans le même format.

### Organisation des contenus

- Un dossier par **domaine de l'examen** (principes fondamentaux, ressources, scheduling, ...).
- Un fichier Markdown numéroté par **notion**, pour garder un ordre de lecture cohérent.
- Un fichier `questions-et-reponses-utiles.md` en fin de domaine, pour l'auto-évaluation.
